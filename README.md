main.py resolves the output directory (MAKEFUN_OUTPUT_DIR, else /output), creates it if needed, and writes a single 173-character line to entry.txt in UTF-8 with no trailing newline.

The line is aimed at the judge's criteria in order: it is plainly an alien tourist's review of Earth, the joke comes from an outside angle on ordinary Earth life (eight billion creatures who stay silent until a shared plate of small fried things appears rather than the first obvious thoughts of traffic, gravity, money or weather), and the verdict "Would orbit again" closes the line so the punch lands at the end.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py && cat out/entry.txt
```
